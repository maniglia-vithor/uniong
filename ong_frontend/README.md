# Frontend do UniONG

React 19 + Vite. Instalação, testes e implantação: veja o [README da raiz](../README.md).

- `npm run dev`: servidor de desenvolvimento (proxy de `/api` e `/c/` para `VITE_PROXY_API`, padrão `http://127.0.0.1:8000`)
- `npm test`: Vitest + Testing Library
- `npx oxlint`: lint
- `npm run build`: build de produção em `dist/`
